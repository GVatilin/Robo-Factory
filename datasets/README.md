# Датасеты

Файлы данных в этой папке не хранятся в git. В репозитории есть только скрипт загрузки `load_datasets.py` и этот README.

## Какие файлы положить

| Файл | Что это | Как скрипт его находит |
|---|---|---|
| `catalog_export_v4.csv` | Каталог решений организатора | Самый свежий `catalog_export*.csv` по имени |
| `Датасеты_хакатон.xlsx` | Демо-параметры склада, аэропорта и медучреждения | Любой `.xlsx` с листами «Склад», «Аэропорт», «Медучреждение» |
| `reference_specs.json` | ТТХ эталонных решений из «Примеры_решений_типы_объектов.docx» с источниками | Точное имя |

Если файла нет, соответствующий шаг пропускается.

## Как загрузить

Backend должен быть запущен: при старте он создаёт базовые справочники, от которых зависят датасеты.

```bash
docker compose up -d
docker compose exec backend python /datasets/load_datasets.py
```

Папка `datasets/` смонтирована в контейнер backend как `/datasets` только для чтения.

Скрипт выполняет все шаги в одной транзакции: при ошибке в данных ничего не сохраняется. Повторный запуск безопасен. Файл с той же контрольной суммой пропускается, а новая версия обновляет данные и записывается в `dataset_versions`.

Другие пути к файлам:

```bash
docker compose exec backend python /datasets/load_datasets.py \
  --catalog /datasets/catalog_export_v5.csv --facilities /datasets/other.xlsx
```

Запуск с хоста без Docker. Нужны зависимости из `backend/requirements.txt` и доступ к БД:

```bash
export DATABASE_URL=postgresql+asyncpg://robo:robo@localhost:5433/robofactory
python datasets/load_datasets.py
```

## Что загружается

1. **Каталог:** продукты, производители, применения по отраслям с кейсами, цены как предложения.
2. **Параметры объектов:** описания параметров с единицами, диапазонами, значениями по умолчанию и источником.
3. **Эталонные ТТХ:** значения характеристик с источником и датой. Продукты, которых нет в каталоге, добавляются.
4. **Демо-проекты:** по одному на тип объекта, с тремя сценариями.

Логика разбора файлов находится в `backend/app/services/`. Её же будут использовать админские роуты загрузки.
