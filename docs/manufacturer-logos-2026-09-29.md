# Логотипы производителей — 29 сентября 2026

Загружены 103 логотипа для 104 реальных компаний каталога. Ещё одна запись —
вымышленный демо-вендор. Для ООО «Кингпро» логотип не подтверждён: сайт
kingpro.global возвращает страницу хостинга; одноимённый дистрибьютор одежды
king-pro.ru — другая компания. Обе записи сохраняют аватар с инициалами.

## Источники и качество

Полный перечень компаний, адреса страниц и оригиналов, дата получения,
контрольные суммы и примечания находятся в
`datasets/manufacturer_logos/manifest.json`. Подготовленные WebP-файлы находятся
в соседнем каталоге `assets/`. Изображения отобраны вручную после автоматического
сбора: логотипы клиентов, партнёров, социальных сетей и заглушки исключены.

Основные источники — сайты производителей. Там, где сайт недоступен, использованы
профили компаний на отраслевых площадках, порталах регионов и партнёров; это
указано в примечании. Например, ЭВР — портал ОЭЗ «Технополис Москва», Агробит —
книга проектов Сколтеха, Виафор — промышленный портал Краснодарского края.
Для Сбербанка использована копия логотипа с Wikimedia Commons с атрибуцией.
Дата получения означает дату нашей загрузки, а не дату разработки логотипа.
`approved` означает ручной отбор изображения, а не официальное одобрение
платформы правообладателем. Логотипы используются для идентификации компаний.

Для ООО «Атоммаш» выбран сайт предприятия из Пензы atom-mash.com, а не
одноимённого предприятия Росатома. Для компаний, работающих под отдельным
брендом, указана связь бренда с компанией. Некоторые небольшие компании
публикуют только значок сайта или растровый логотип небольшого разрешения.

## Отображение и хранение

- Список производителей и страница компании.
- Производитель в карточке решения и на странице решения.
- Предпросмотр в форме редактирования компании.
- Раскрываемый блок «Источник логотипа»: страница, оригинал, дата и примечание.

Метаданные хранятся в `manufacturers.logo_metadata` (JSONB); файл — в постоянном
томе `/data/uploads/manufacturer-logos/<sha256>.webp`. Публичный маршрут принимает
только контрольную сумму и расширение WebP, не произвольный путь или внешний URL.
Браузер получает изображения с нашего сервера. Если файла нет или он не
загрузился, отображается аватар с инициалами.

## Обновление

После ручного отбора измените manifest и положите файл с соответствующей
контрольной суммой в `assets/`. Скрипт `discover_manufacturer_logos.py` помогает
собрать кандидатов; он не утверждает и не публикует их автоматически.

Локальный импорт после миграции:

```powershell
docker compose exec -T backend python /datasets/load_manufacturer_logos.py
```

Скрипт запускается в окружении backend и использует его подключение к БД.
Сопоставление выполняется по полному имени производителя. Неизвестные компании
пропускаются; производители, товары, проекты и пользователи не создаются и не
удаляются. Повторный импорт не меняет уже совпадающие записи. Метаданные с
`uploaded_by_id` защищены от пакетной перезаписи.

Скрипт развёртывания автоматически импортирует пакет после успешного запуска
контейнеров. Резервная копия БД создаётся стандартным этапом развёртывания.
