# Российский каталог

С 29.09.2026 активный каталог ограничен российскими производителями и моделями.
Проверяются две страны: производителя и происхождения продукта. Неизвестная
страна и российский интегратор иностранного оборудования не проходят фильтр.
Значение страны берётся из данных карточки: фильтр сам не подтверждает их
достоверность. При заполнении необходимо сохранить официальный источник.

Старые иностранные записи сняты с публикации и исключены из каталога,
производителей, сравнения и автоматического подбора, в том числе у администратора.
Физически записи остаются в БД для сохранения связей старых сценариев.
Миграция сохраняет предыдущий статус публикации для отката.

Ручное добавление и изменение требуют российскую страну модели и производителя.
Новые строки CSV должны содержать колонки `Страна происхождения` и
`Страна производителя`. У существующих строк можно сохранить ранее указанные
страны. Только два исходных файла организатора, определяемые SHA-256, сохраняют
совместимость со старым форматом, где указаны российские регионы.

Исторические пакеты расширения неизменны, поскольку их контрольные суммы уже
записаны в БД. При установке на пустую БД загрузчик пропускает иностранные модели
и не создаёт их производителей; повторный деплой не возвращает их в каталог.
Новые пакеты должны содержать только российские модели с официальными источниками
характеристик и фотографий. Импорт эталонных ТТХ и примеров также ограничен страной.
