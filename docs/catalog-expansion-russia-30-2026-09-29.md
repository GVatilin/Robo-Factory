## Проверка источников

- Российское происхождение: [производство ROBOTECH](https://robotech.digital/company/research-product-base/), [ТАРИС](https://taris.ru/about), [Промобот](https://promo-bot.ru/about-us/).
- Для каждой характеристики сохранены официальный URL, дата получения и признак подтверждённости. Подтверждение означает публикацию производителя, а не независимое испытание.
- У фотографий есть исходный URL, страница публикации, хеш оригинала и локальной копии. Фото визуально проверены. Повторные изображения исполнений отмечены в подписи.
- В стоимости неизвестное не заменено нулём. Публичные цены, срок службы и другие неподтверждённые параметры остаются незаполненными.

## Особенности

- ROBOTECH RX-60/2300: опубликованная грузоподъёмность 55 кг, хотя название содержит 60. Сохранена таблица с примечанием об уточнении.
- Досягаемость манипуляторов указана в описании, не подменяет габариты. Повторяемость ± указана с пояснением; угловая скорость не подменяет м/с.
- SIGMA 100D, 150, 200 и 250A — отдельные исполнения существующего семейства, параметры между ними не переносятся.
- Для SIGMA 200 размеры относятся к транспортному модулю без подъёмника камеры. Для ТР 250 — без колёс, масса с аккумулятором.
- Для автономных ТАРИС дальность без кабеля отделена от дистанции работы с кабелем. Температура батареи не перенесена на весь робот.
- Promobot Robo-C2 не наследует характеристики V.4. Параметры API взяты из официальной базы знаний, совместимость плагинов зависит от модели.
- Процесс склада назначен только моделям с явно заявленным паллетированием; диагностика труб и консультирование не выдаются за складскую перевозку.
